# Communiqué Letter Generator (Chrome Extension)

A professional letter generator with real-time A4 preview, manual table breaks, and draggable signatures. Designed for batchmates to quickly generate formal letters.

## How to Install 


1.  **Download the Code**:
    *   Click the green **"Code"** button at the top of this GitHub page.
    *   Select **"Download ZIP"** and extract the folder on your computer.

2.  **Open Extensions Page**:
    *   Open Google Chrome.
    *   In the address bar, type `chrome://extensions/` and press Enter.

3.  **Enable Developer Mode**:
    *   Toggle the **"Developer mode"** switch in the top right corner to **ON**.

4.  **Load the Extension**:
    *   Click the **"Load unpacked"** button.
    *   Navigate to the folder you just extracted.
    *   Select the **`Communique_extension`** folder inside it.

## How to Use

*   Click the **Communiqué logo** in your Chrome toolbar.
*   The generator will open in a full-sized new tab.
*   Fill in the details, use the **Scissors** icon to break tables across pages, and drag the **Signature** anywhere you need it.
*   Click **"Save as PDF"** when finished!
